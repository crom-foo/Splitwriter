Splitwriter 2.0 Plain (Portable) — Windows x64

2.0 PLAIN RELEASE
- Added rolling backups for changed manual saves (Ctrl+S and Save), keeping the
  latest 10 snapshots per project in `_Backups`. Autosave remains separate and
  does not consume the manual-save change state.
- Standardized generated project subfolders as `_Backups` and `_Images`.
- Added paragraph-indentation controls for display and plain-text copy/export,
  including TextBoard and Manuscript View.
- Improved plain-text copy, partial-selection indentation, and paste handling.
- Improved Navigator group and board reordering, moving boards out of groups,
  multi-board deletion, and drag feedback at narrow drop boundaries.
- Kept the text caret stable when applying alignment from toolbar buttons, and
  made Echo View start markers follow their paragraph and clear when it is
  deleted.
- Added the em dash shortcut (Alt+-) and updated the About shortcut guide.
- Made the saved theme and accent settings apply reliably on startup.
- Separated the v2 WebView2 data location from older Splitwriter versions.
- Removed the unreliable native spell-check integration from the 2.0 beta.
- Kept F12 and Ctrl+Shift+I DevTools available in this evaluation build.

BETA 4 FIXES AND IMPROVEMENTS
- Added board duplication from the Navigator context menu and Ctrl-drag pane
  duplication for TextBoards.
- Improved board deletion: open panes close before deletion, the pane being
  removed is highlighted during confirmation, and one Writing board is kept.
- Improved Windows PDF print-dialog status and recovery when printing fails or
  the dialog closes.
- Expanded the rightmost TextBoard scrollbar hit area without changing its
  visible position, and kept the app window within the available screen area.
- Added the middle dot (Alt+.) shortcut and refined the About shortcut guide.
- Fixed paragraph indentation preset loading and preferences select typing.

BETA 3 FIXES AND IMPROVEMENTS
- Improved manuscript typography, paragraph spacing, indentation, and paste
  handling so the manuscript reflects the source boards more consistently.
- Added a visible Echo View start marker using the user's Accent Color.
- Improved image board missing-file details and image duplication behavior.
- Improved autosave safety after opening a project and kept the enable action
  visible while autosave is paused.
- Updated dropdowns, context menus, dialogs, navigator interactions, and board
  accents to use the selected theme and custom Accent Color consistently.
- Removed Scenario Board from the Change Board options; existing project data
  remains readable for compatibility.
- Marked Archive as coming in version 3.0.
- Fixed paragraph paste behavior, anchor-board state, and navigator menu
  dismissal issues found during beta testing.

BETA 2 FEATURES

BETA 2 FIXES
- Keep the Anchor Board marker in sync when opening another board in the
  Anchor Pane.
- Restore unlinked text from older SWON projects to Notes, and ignore empty
  placeholder text when creating recovered boards.
- Replace native Open/New unsaved-change prompts with the in-app dialog.

WHAT'S NEW
- Reworked Navigator with Writing and Notes boards, groups, drag-and-drop
  ordering, and independent Main and Draft writing orders.
- Added board context actions, delete confirmation, and Anchor Pane opening.
- Added Manuscript View with TXT and PDF export in the current order.
- Added pane splitting and pane position swapping by dragging pane handles.
- Added board creation from split panes and improved image board accents.
- Added keyboard input language preferences, manuscript spacing, and updated
  preferences and presets.
- Refined light and dark themes, selection colors, separators, and dialogs.
- Added safeguards that pause autosave after opening an existing project.

BETA NOTES
- This release is intended for hands-on testing. Keep backup copies of
  important .swon projects and report reproducible issues.
- Older projects remain supported; save a copy before testing beta workflows.
