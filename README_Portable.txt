Splitwriter v1.2.0 Portable
Windows x64

GET STARTED
1. Extract the package to a folder.
2. Run Splitwriter.exe.

REQUIREMENTS
Windows 10 (version 1803 or later) or Windows 11.
Microsoft Edge WebView2 Runtime is required. If Splitwriter does not start,
install the Evergreen WebView2 Runtime from:
https://developer.microsoft.com/microsoft-edge/webview2/

PROJECT FILES AND PRIVACY
Splitwriter projects use the .swon file format. Choose where to save each
project from inside the app. The app does not require an account or network
connection for writing.

PDF EXPORT
Right-click a text board handle, choose Export as, then PDF. Use the Windows
print window to select a printer or save the document as a PDF.

WINDOWS SMARTSCREEN
This portable build is not digitally signed. If SmartScreen appears, choose
More info, then Run anyway.
